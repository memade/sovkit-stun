# sovkit-stun v0.1.0-preview.1

首个开发预览。独立 IPv4 UDP STUN Binding 服务与 C++20 静态库，不是 Nearvia 客户端，
也不包含完整 SovKit SDK。源码使用 MIT，保留原始版权与导出记录。

## 提供什么

- 双端口 Binding、XOR-MAPPED-ADDRESS、可选 FINGERPRINT。
- 每来源与全局限速，默认只监听本机；跨端口诊断扩展默认关闭。
- 命令行配置、信号退出与汇总 JSON 日志；不写业务数据库或应用缓存。
- 安装式静态库、公共头文件、CMake 包和独立宿主示例。

## 下载选择

| 附件 | 用途与限制 |
| --- | --- |
| macos-arm64-preview 源码摘要命名的 tar.gz | Apple Silicon 命令行程序 + STUN 静态库 SDK；不是图形客户端 |
| source-preview 源码摘要命名的 tar.gz | 白名单源码、测试、示例和文档；用于 Linux 或自行构建 |
| SHA256SUMS | 两个附件的 SHA-256 校验摘要 |

从 [该预览的 Release 页面](https://github.com/memade/sovkit-stun/releases/tag/v0.1.0-preview.1)
下载后，在附件所在目录执行 shasum -a 256 -c SHA256SUMS。
解压后的 manifest.json 与 SHA256SUMS 提供来源、平台、依赖和逐文件校验。
manifest 的 published: false 是离线生成时的状态，不反映 GitHub 后续发布操作。

macOS 程序静态链接 libuv 1.52.1，仅依赖系统动态库；随包保留对应 libuv 许可。
SDK 静态库仍需消费方提供公共 libuv ≥ 1.44，不承诺跨编译器的 C++ ABI。
最低编译目标为 macOS 13，实际验证为 macOS 26.6.2 / arm64；没有旧系统实测、Developer ID 签名或公证。
不提供绕过系统安全检查的安装步骤；如需要不同平台或可信本地构建，请使用源码。

## 验证与边界

- macOS arm64：Release 与 ASan/UBSan，CTest 5/5。
- Linux ARM64：OrangePi Zero2 W / Debian 12，原生 Release，CTest 5/5。
- 包含 11 项 UDP 测试、20,000 组确定性 parser 样本、SDK 安装迁移；
  Linux 快照有 8 项打包检查，发布前新增第 9 项完整许可检查在 macOS 通过。

首版不提供 Linux、Windows、Android 或 iOS 二进制。Linux 实机验证仅覆盖板内回环及 SDK 接入；
没有 systemd 部署、跨公网、长期运行或多来源容量压测结论。
非完整 RFC 8489 / RFC 5780 实现，不支持 IPv6/TCP/TLS STUN、TURN、数据中继或 ICE agent。
Binding 结果不能保证客户端能互相直连。不要把默认回环验证当作公网服务安全验收。
